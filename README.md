# Personal Full-Stack Portfolio

A full-stack portfolio application built as both a professional portfolio and a capstone learning project.

The project emphasizes modern software engineering practices, maintainable architecture, and incremental, milestone-driven development. In addition to showcasing completed features, it documents the architectural decisions, implementation process, and lessons learned throughout the project's lifecycle.

## Technology Stack

### Frontend

* Vue.js
* Bootstrap

### Backend

* Node.js
* Express.js

### Database

* MongoDB Atlas
* Mongoose

### Authentication

* JSON Web Tokens (JWT)
* bcryptjs

### Deployment

* Vercel
* AWS Lambda
