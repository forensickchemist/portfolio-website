## Development Workflow

This project follows an incremental, feature-oriented development process.

Each feature progresses through the following stages:

1. Planning
2. Architecture discussion
3. Incremental implementation
4. Testing
5. Documentation
6. Git commit
7. GitHub Project update

Every completed feature should conclude with:

* Updating all affected documentation.
* Recording significant architectural decisions as Architecture Decision Records (ADR), when appropriate.
* Writing a conversation summary.
* Preparing the continuation prompt for the next feature.
* Updating the GitHub Project board.

This workflow ensures that implementation, documentation, and project management remain synchronized throughout the project's lifecycle.
