# Personal Full-Stack Portfolio

A full-stack portfolio application built as both a professional portfolio and a capstone learning project.

## Tech Stack

- Frontend: Vue.js, Bootstrap
- Backend: Node.js, Express.js
- Database: MongoDB Atlas
- Authentication: JWT, bcryptjs
- Deployment: Vercel, AWS Lambda

## Project Goals

- Showcase full-stack development skills
- Demonstrate software engineering practices
- Document architectural decisions and learning journey
- Build a maintainable, production-ready portfolio

## Documentation

Project documentation is organized under the `docs/` directory.

- `docs/published/` — Public technical documentation
- `docs/private/` — Private development notes
